# بوابة تحضير معهد أسس التقنية والقانون

بوابة حضور وانصراف فيها قسمين:

- **بوابة الشؤون الأكاديمية:** يدخلها حسابين، الإدارة ومسؤول الشؤون الأكاديمية، كل واحد برمزه. يضيفون المدربين والمقررات والطلاب، ويتابعون التقارير.
- **بوابة المدربين:** كل مدرب يدخل باسمه ورمزه، ويحضّر طلابه فقط.

الموقع على GitHub Pages، والبيانات على Firebase، وتسجيل الدخول فيه حقيقي. قواعد الحماية تمنع أي مدرب يعدّل غير تحضير مقرراته، ورموز المدربين ما يشوفها غير الشؤون الأكاديمية.

> ⚠️ ملف `asas-seed.json` فيه أسماء الطلاب ورموز المدربين. **لا ترفعه على GitHub.** ملف `.gitignore` يمنع رفعه تلقائياً.

---

## ١) إنشاء مشروع Firebase (مجاني)

1. ادخل [console.firebase.google.com](https://console.firebase.google.com) بحساب Google، واضغط **Create a project**. سمّه مثلاً `asas-attendance`، وتقدر تطفي Google Analytics.
2. **تسجيل الدخول:** من القائمة اختر **Build ← Authentication ← Get started**، ثم من **Sign-in method** فعّل **Email/Password**. فعّل الخيار الأول فقط.
3. **حسابات الشؤون الأكاديمية:** في Authentication روح لتبويب **Users**، واضغط **Add user** مرتين:

   | الصفة | Email | Password (هذا هو رمز الدخول) |
   |---|---|---|
   | الإدارة | `admin@asas.local` | رمز من ٨ أرقام تختاره |
   | مسؤول الشؤون الأكاديمية | `academic@asas.local` | رمز من ٨ أرقام تختاره |

   لا تغيّر الإيميلات نفسها، لأن البوابة تتعرّف على الصفة منها.
4. **قاعدة البيانات:** من **Build ← Firestore Database ← Create database** اختر أقرب موقع يطلع لك، مثل `me-central2` (الدمام) إذا كان متاح، واختر **Production mode**.
5. **قواعد الحماية:** في Firestore افتح تبويب **Rules**، امسح اللي فيه، والصق محتوى ملف `firestore.rules` كامل، ثم اضغط **Publish**.
6. **إعدادات الموقع:** روح لـ **Project settings** (أيقونة الترس) ← **Your apps**، واضغط أيقونة الويب `</>`. سجّل تطبيق باسم `portal`، وما تحتاج Hosting. بيطلع لك كود فيه `firebaseConfig`: انسخ القيم، وحطها في ملف `config.js`.

## ٢) رفع الموقع على GitHub Pages

1. في GitHub سوّ مستودع جديد، مثلاً `asas-attendance`.
2. ارفع هالملفات: `index.html` و`app.js` و`config.js` و`firestore.rules` و`README.md` و`.gitignore`. **لا ترفع `asas-seed.json`.**
3. من **Settings ← Pages** اختر **Deploy from a branch**، والفرع `main`، والمجلد `/ (root)`، ثم احفظ.
4. بعد دقيقة يصير الرابط: `https://اسمك.github.io/asas-attendance/`
5. ارجع لـ Firebase: **Authentication ← Settings ← Authorized domains ← Add domain**، وأضف `اسمك.github.io`.

## ٣) التشغيل الأول

1. افتح رابط البوابة، وادخل **بوابة الشؤون الأكاديمية** بصفة الإدارة ورمزها.
2. روح لتبويب **المدربين والرموز**، وتحت عند **استيراد البيانات الأولية** اختر ملف `asas-seed.json` واضغط **استيراد**. ينشئ 9 مدربين برموزهم الحالية و21 شعبة فيها كل الطلاب.
3. خلاص. أرسل لكل مدرب رابط البوابة ورمزه، وتقدر تستخدم زر **نسخ الرمز**.

## ملاحظات

- **رمز جديد لمدرب:** ينشئ له حساب دخول جديد، والقديم يتوقف عن العمل. الحسابات القديمة تقدر تحذفها من Authentication ← Users إذا تبي، والبوابة شغالة بدون ما تحذفها.
- **تغيير رمز الإدارة أو الشؤون الأكاديمية:** من Firebase ← Authentication ← Users احذف الحساب، ثم أضفه من جديد بنفس الإيميل والرمز الجديد. لا تستخدم زر Reset password، لأنه يرسل إيميل والإيميلات هنا داخلية ما توصل لأحد.
